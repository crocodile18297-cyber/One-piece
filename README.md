# ONE PIECE: GRAND ARENA

A browser-based 3D multiplayer arena prototype. Built with Three.js, Express and Socket.IO.

## Features
- Third-person 3D arena and procedural pirate avatar
- Gear 2, Gear 3, Gear 4 (Boundman) and Gear 5 visual modes
- Pistol, Gatling and Kong Gun-style visual attacks
- Real-time player presence and movement over Socket.IO
- Keyboard and touch controls

## Run locally
`npm install && npm start`

Open `http://localhost:3000` in two browser tabs to test multiplayer.

## Deploy
Render web service: build command `npm install`, start command `npm start`, runtime Node, root directory `.`.

This is the first playable foundation; full character models, hit detection, quests, islands and persistent progression are later milestones.
